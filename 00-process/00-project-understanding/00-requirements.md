# Requirements

## Outcome: How it needs to run and behave?

    - one command with input topic(no intermediate decisions or steering)
    - 10-20 candidate startups
    - Structured analysis of each startup covering: team, product, market, risk/open questions, out of 100 score against thesis
    - A one page memo per startup
        - Each Recommendation must end with Pass / watch / take a meeting
        - Mark top 10-20% with Take a meeting call
        - Rationale and 2-3 points for each that will change our mind about the startup 
        - one page memo has a 60 second target to deliver all insights
        - spot check and validate analysis and it's trace/source/citations
    - clear understanding of the working process implemented

## Output: What do we want?

    - A 5 minute video for one of the output memos
    - Code repo with clear stage separation
    - Transparent Process and AI workflows used
    - committed generated outputs

## Fallout: What we don't want?

    - code dump without transparency and process flow
    - AI written reflective writing about code and model usage
    - post-fact fillers
    - garbage or unintended results from a selected pool of source
    - sourceless claims
    - a broad thesis which tries and includes everything

## Constraints: What do we build with?

    - public data only(free tiers, non commercial, open source)
    - no fullstack app(no frontend), no vector DB or DBs
    - any LLM model
    - tech stack of choice which respects all constraints

## Evaluation: What matters most?

    - How I build it and how AI was used:   Process & AI workflow visibility (40%)
    - What I build:                         Output quality (20%)
    - Scoping and assumptions:              Scoping & judgment (20%)
    - How I designed it:                    System design (10%)
    - Best practices:                       Code quality (10%)

## Rules

    - Use of AI is permitted
    - Honest work segmentation: AI vs me
    - No ghostwriting
    - No text wall and dump to fill in spaces
